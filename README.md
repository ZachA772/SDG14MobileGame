# H2(O)h No!# (Unity Project)

This project is a 2D arcade shooter developed using Unity and C#. The player controls a diver and must survive waves of various different enemies.

The project was designed around SDG 14: Life Below Water.

## Features

•	Player movement
•	Shooting system
•	Multiple Levels
•	Multiple enemy types
•	Multiple Bosses
•	Power-ups
•	Collision detection
•	Sound effects
•	UI displaying score, Boss Names/Health Bars

## How to Run the Project in Unity

1. Open Unity Hub  
2. Click "Open Project From Disk"  
3. Select the SDG14MobileGame folder  
4. Open the scene from Assets/Scenes
5. Click Play
  

## Controls

Desktop:
• Move: WASD or Arrow Keys  
• Shoot: Left Mouse on the "Shoot" Button  

Mobile:
• Touch controls
